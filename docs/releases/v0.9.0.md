# DockNotes v0.9.0

这是 v0.3.0 之后的完整功能更新。下载包适用于 Apple Silicon Mac，要求 macOS 15 或更高版本。

## 新增与改进

- 工作区：将侧边便签按项目或场景分组，支持切换、排序、跨组移动、管理、撤销删除，以及 `⌥⌘1…9` 快捷切换。旧版便签迁入默认工作区，迁移前文件会保留备份。
- 任务中心：集中查看所有工作区的待办、今天、未来 7 天、即将到期、逾期和已完成任务。
- 重复任务：支持每天、工作日、每周、每月及自定义间隔，并可跳过一次、单次改期或修改整个系列。
- 提醒与日历：任务到期通知、每日摘要，以及与选定的可写系统日历同步；日历冲突由用户选择处理方式。
- 便签库：支持搜索、筛选、排序、预览、批量移动、导入导出和归档管理。
- 设置、任务中心、便签库与工作区管理改为中性 glass 风格，并支持窗口同时显示。

## 修复

- 修复侧边标签点击、展开便签与桌面便签四角的显示问题。
- 修复设置、任务中心和便签库切换时窗口被关闭或已打开窗口无法回到前台的问题。
- 改进工作区弹窗定位、标签切换与侧边标签显示状态。
