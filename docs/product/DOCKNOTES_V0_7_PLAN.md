# DockNotes v0.7 实施计划

状态：已完成

制定日期：2026-09-23

版本主题：让周期任务自然进入每周计划

## 1. 版本目标

v0.7 在现有任务中心和本地通知之上增加重复任务与未来七天计划。重复信息只存放在任务元数据中，正文继续保留一条可读、可编辑的复选框文本；完成当前实例后推进到下一实例，不向正文复制任务。

## 2. 数据契约

- 每个正文任务继续使用稳定 `NoteTask.ID` 作为系列身份。
- 重复状态保存规则、当前计划日期、单次改期/跳过以及完成历史。
- `dueDate` 表示当前实例的实际到期时间；当前计划日期保留未改期前的系列节奏。
- 完成重复任务时记录当前实例、把正文复选框恢复为未完成并推进到下一有效实例。
- 停止重复后保留当前实例为普通任务，不删除正文或历史。
- 新字段使用可选解码，旧便签、旧任务元数据和现有设置无需迁移操作即可继续使用。

## 3. 用户能力

- 规则：每天、工作日、每周、每月，以及自定义间隔。
- 操作：完成当前实例、跳过本次、推迟本次、修改本次、修改整个系列、停止重复。
- 计划：任务中心提供未来七天视图，按实际日期展示当前实例及后续投影。
- 来源：所有实例均可回到唯一来源便签；正文不会生成重复行。
- 编辑：日期和重复规则在同一任务弹层中完成，并明确区分“仅本次”和“整个系列”。

## 4. 提醒与生命周期

- 当前实例通知使用系列任务 ID 与计划日期组成的稳定标识。
- 完成、跳过、单次改期或整组修改后，旧通知取消并为新的当前实例重新安排。
- 每日摘要和未来七天计划使用同一重复计算规则。
- 归档、删除时取消系列通知；恢复、撤销删除、应用重启、系统唤醒和时区变化时重建。

## 5. 发布门槛

- 自动化覆盖所有规则的跨日、跨周、月末与闰年计算。
- 自动化覆盖完成推进、正文直接勾选、跳过、单次改期、整组修改、停止重复及持久化重载。
- 自动化覆盖七天投影的稳定身份、去重、搜索和日期边界。
- 自动化覆盖通知重排、摘要计数、归档/删除/恢复和旧数据兼容。
- 完整自检、交互回归、Release 构建、签名检查、差异检查和真实应用走查通过。
