# DockNotes MVP 产品需求

> 状态：Draft 0.1  
> 日期：2026-09-09  
> 平台：macOS 15+  
> 竞品依据：[Tucky 产品拆解](../research/tucky/PRODUCT_TEARDOWN.md)

## 1. 产品目标

DockNotes 是一个本地优先的 macOS 边缘便签应用。它让用户不必切换窗口，就能快速记录、隐藏、找回和整理短笔记与待办。

MVP 要完成的核心闭环：

**全局快捷记录 → 自动保存在本机 → 收回屏幕边缘 → 快速重新打开 → 搜索或归档。**

## 2. 产品原则

1. **Tucky 核心体验的忠实复刻优先于视觉再设计。** 未经用户确认，不把便签标题解释成分类，也不为 Edge Deck 自创图标、异形轮廓或信息层级。
2. 本地功能永久免费，不限制便签数量。
3. 便签即使离线或版本需要更新也始终可读、可编辑、可导出。
4. AI 是可选增强，不是打开便签的前置条件。
5. 不上传便签、使用数据或屏幕内容，除非用户明确启用相应功能。
6. 中英文是一等公民，不把中文当成英文界面的附加翻译。
7. 使用原生 macOS 交互、键盘导航和系统无障碍能力。

## 3. MVP 范围

### 3.1 Edge Deck

- 便签以标签吸附在屏幕左侧或右侧。
- 每一个标签就是一张便签，不存在由标题推导出的“大分类”层级。
- 展开某张便签时，该标签移动为编辑器左侧书脊；其余标签继续停靠在屏幕边缘。
- 收起仅关闭当前便签编辑器，所有便签仍分别保留自己的边缘标签。
- Deck 必须使用独立透明窗口；透明区域不得出现灰黑底板、窗口阴影或不可点击的大面积遮挡层。
- 指针进入检测区时展开，离开后收回。
- 点击标签打开便签；可选悬停预览。
- 支持固定便签，使编辑器保持打开。
- 标签展示颜色和标题，标题过长时单行截断并提供完整辅助说明。
- 标签过多时显示溢出数量，点击进入 All Notes。
- 可显示标签数必须由当前屏幕可用高度、标签高度和控制区高度计算；不得写死为固定数量。
- 展开活动便签时保留其原始 Deck 槽位，其他标签不得补位；收起后标签回到同一位置，不产生乱序或跳动。
- 超过容量的便签集中在 `+N` 弹出列表中，`N` 只统计当前未显示且处于收起状态的便签。
- 提供新增按钮。
- 记住每台显示器上的边缘和垂直位置。
- 显示器移除后自动迁移到主屏幕，不把窗口遗留在不可见区域。

### 3.2 便签编辑器

- 新建、打开、编辑、关闭、重命名。
- 自动保存，并显示 `正在保存 / 已保存 / 保存失败` 状态。
- 8 种可区分的颜色；颜色不是唯一识别方式。
- 支持为单张便签输入精确 RGB（0–255）或 6 位 Hex 自定义颜色，并持久保存。
- 默认材质为接近 Tucky 的纯色；纸张纹理是每张便签可选的外观材质，不作为全局唯一主题。
- 固定、取消固定。
- 归档和恢复。
- 删除后进入 10 秒可撤销状态；MVP 暂不提供永久回收站。
- 支持纯文本与实时 Markdown 样式。
- 支持任务复选框。
- 支持到期日期。
- 支持当前便签内查找。
- 支持常规撤销、重做、剪切、复制和粘贴。

### 3.3 All Notes

- 左侧列表、右侧编辑器的双栏结构。
- All Notes / Archive 切换。
- 按标题与正文搜索。
- 按最近修改排序；可切换 `到期优先`。
- 列表项展示颜色、标题、修改时间和一行摘要。
- 空列表、无搜索结果、Archive 为空时分别显示对应空状态。
- 底部提供新建、导出和数量统计。

### 3.4 提醒与日历

- 为便签设置或清除到期日期。
- 可选：每天早晨汇总提醒当天到期便签。
- 提醒时间可配置，默认 08:00。
- 可选：将到期便签映射为 Calendar.app 全天事件。
- 清除到期日或删除便签时，同步移除对应事件。
- 在写入 Calendar 前解释权限用途；拒绝权限后便签功能仍正常。

### 3.5 导入与导出

- 导出 Markdown：每张便签一个文件。
- 导出纯文本：每张便签一个文件。
- 导出单一 Markdown 文档。
- 从 Markdown / TXT 文件导入。
- 文件名冲突时自动追加序号，不覆盖用户已有文件。
- 导出不包含加密后的内部数据格式。

### 3.6 全局快捷键

默认快捷键允许用户修改，并检测系统或应用冲突。

| 快捷键 | 动作 |
| --- | --- |
| `⌥⌘N` | 新建便签 |
| `⇧⌘Space` | 快速记录 |
| `⌥⌘A` | 打开 All Notes |
| `⌥⌘L` | 打开 Archive |
| `Esc` | 关闭当前便签 |
| `⌘F` | 当前便签内查找 |
| `⌘T` | 切换任务状态 |
| `⌘P` | 固定/取消固定 |
| `⌘.` | 循环切换颜色 |
| `⌘⌫` | 删除并进入撤销期 |

## 4. 中英文语言切换

### 4.1 用户设置

在 `设置 → 通用 → 语言` 提供三个选项：

1. `跟随系统 / System Default`（默认）
2. `简体中文`
3. `English`

切换后应立即更新所有 DockNotes 窗口、菜单栏菜单和 Edge Deck，不要求退出或重启应用。设置持久保存，并在下次启动时先于首个窗口生效，避免界面先闪现错误语言。

### 4.2 本地化覆盖范围

必须本地化：

- 设置页、菜单栏菜单和右键菜单。
- 按钮、工具提示、快捷键说明和 VoiceOver 标签。
- 保存状态、加载状态、错误提示和撤销提示。
- 空状态、权限说明和首次引导。
- 通知标题与正文。
- 导入、导出和系统文件选择器旁的应用文案。
- 日期、时间、相对时间和数量复数规则。

不自动本地化：

- 用户输入的便签标题与正文。
- 用户自定义标签、导出文件名和搜索词。
- Markdown 代码内容和链接地址。

“翻译便签”未来可作为独立的显式功能，不能因为切换界面语言而改写用户内容。

### 4.3 文案与布局规则

- 使用一致术语：`便签 / Note`、`所有便签 / All Notes`、`归档 / Archive`、`固定 / Pin`、`到期日 / Due Date`。
- 快捷键符号保持 macOS 原生写法，不翻译 `⌘`、`⌥`、`⌃`、`⇧`。
- 中文界面使用系统中文字体；英文界面使用系统拉丁字体，避免依赖不完整的手写字体覆盖中文。
- 控件不能依赖固定文本宽度；为英文文案预留约 30% 的长度变化空间。
- 纵向 Edge 标签应优先使用横排旋转整体，而不是逐字竖排，保证中英文都可读。
- 日期显示服从当前应用语言与地区格式，但数据库始终保存稳定的 ISO 日期。
- 搜索、排序和文本截断必须正确处理中文、emoji 和组合字符。

### 4.4 缺失翻译与回退

- 简体中文缺失某个 key 时回退到 English。
- 不允许直接在界面显示本地化 key。
- 开发构建记录缺失 key；发布构建保持可用并上报非敏感错误计数。
- 未完成 100% 核心流程翻译时不得发布该语言。

### 4.5 实现要求

- 使用 Xcode String Catalog（`.xcstrings`），禁止在 SwiftUI / AppKit 视图中硬编码用户可见字符串。
- 应用语言设置通过 `AppleLanguages` 或统一的应用级 Locale 管理层驱动。
- 所有日期和数量使用 `FormatStyle`，不手写语言相关格式。
- 菜单栏、状态栏、通知和 AppKit 面板与 SwiftUI 视图共用同一套本地化 key。
- 为翻译提供开发注释和界面上下文，避免一词多义。
- 为伪本地化保留调试入口，用于检查截断与布局溢出。

### 4.6 验收标准

- 首次启动跟随 macOS 当前语言。
- 用户可以在中文与英文间即时切换，无需重启。
- 已打开的 Edge Deck、编辑器、All Notes 和设置页同时更新语言。
- 切换语言不会修改或重新保存便签正文。
- 中文搜索可以匹配中文标题与正文。
- 中英文通知均显示正确日期和便签数量。
- 所有菜单项、右键项、空状态和错误提示没有遗漏翻译。
- VoiceOver 在两种语言下都朗读正确控件名称和状态。
- 200% 界面缩放和最长文案下没有截断、重叠或按钮消失。

## 5. 设置结构

```text
设置
├── 通用
│   ├── 语言
│   ├── 登录时启动
│   └── 默认提醒时间
├── Edge Deck
│   ├── 样式
│   ├── 左/右边缘
│   ├── 尺寸与检测区
│   ├── 悬停预览
│   └── 全屏应用上方显示
├── 编辑
│   ├── 字体与字号
│   ├── 便签尺寸
│   └── Markdown 样式
├── 快捷键
├── 日历与通知
├── 数据与隐私
└── 导入与导出
```

## 6. 非功能要求

- 冷启动后 500ms 内显示 Edge Deck。
- 输入到落盘的延迟不超过 300ms；崩溃最多丢失最后一次尚未完成的输入事件。
- 10,000 张短便签下，搜索结果首屏在 200ms 内返回。
- 无网络时所有 MVP 便签能力正常。
- 正文加密，密钥存入 macOS Keychain，并支持未来密钥版本轮换。
- 所有窗口均可用键盘关闭，所有核心动作均可不用鼠标完成。
- 尊重 Reduce Motion、Increase Contrast、VoiceOver 和 Dynamic Type 类似的系统可访问性设置。

## 7. MVP 不包含

- 云同步和团队协作。
- 移动端、Windows 或 Web 版本。
- AI、语音、屏幕理解和第三方连接器。
- 富文本附件、图片、表格和手写笔记。
- 便签内容自动翻译。
- 公开分享链接。

这些能力可以在边缘便签核心体验稳定后独立评估，不能拖慢本地 MVP。

## 8. 发布验收主流程

1. 在中文系统首次启动，创建中文便签并收回 Edge Deck。
2. 使用全局快捷键创建英文便签。
3. 在 All Notes 中分别搜索中英文内容。
4. 为便签添加任务和到期日期，验证通知与 Calendar 映射。
5. 切换到 English，确认所有已打开界面即时更新且正文不变。
6. 导出 Markdown，确认中英文文件名和内容编码正确。
7. 断网重启，确认便签仍可读取、编辑和导出。
8. 开启 VoiceOver 与 Reduce Motion，完成新建、搜索、归档和恢复。
