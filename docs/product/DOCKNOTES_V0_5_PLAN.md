# DockNotes v0.5 实施计划

状态：已完成

制定日期：2026-09-22

版本主题：从便签里的待办，形成每天可管理的任务中心

## 1. 版本目标

v0.5 将正文中的 `☐`、`☑`、`□`、`✓` 识别为任务，但仍以原便签正文作为事实来源。用户可以集中查看、搜索、勾选任务，设置独立截止时间，并随时回到来源便签。

同时补齐 Markdown/TXT 导入导出，让本地数据具备可迁移、可读和可备份能力。

## 2. 当前实现

- 任务中心独立窗口，以及侧边标签、便签库和状态栏入口。
- 待处理、今天、即将到期、已逾期、已完成五个视图及实时计数。
- 同时支持整行和行内复选框，不复制正文数据。
- 在任务中心勾选后精确回写来源便签，并保留 RTF 格式。
- 每个任务拥有独立截止时间；在正文插入、移动或修改任务时尽量保持原任务元数据。
- 搜索同时匹配任务文字和来源便签标题。
- Markdown/TXT 批量导入导出；Markdown 任务语法与 DockNotes 复选框双向转换。
- 导出文件名清理和重名避让，不覆盖已有文件。

## 3. 发布门槛

- 同一便签内多个任务可以拥有不同截止时间，并能在重启后恢复。
- 在任务中心勾选任务后，来源便签立即更新；从来源便签勾选后，任务中心立即更新。
- 新任务插入到已有任务之前，不会把截止时间错误转移给新任务。
- 今天、即将到期、已逾期和已完成互不产生错误重复。
- 搜索、分类、来源跳转和日期弹窗可通过键盘访问。
- Markdown/TXT 导入导出支持中文、英文、复选框和同名文件。
- 完整自检、交互回归、Release 构建和真实应用走查全部通过。

## 4. 验收记录

- 任务中心五个视图、搜索、计数、日期弹窗和来源跳转已完成真实应用走查。
- Markdown/TXT 的转换、中文内容、复选框元数据和同名文件已纳入自检；真实文件选择器已走查。
- 任务中心使用系统可访问控件，并为任务勾选按钮提供稳定的辅助功能标识。
- 完整自检、交互回归、Release 构建、应用重启和真实界面检查均已通过。
