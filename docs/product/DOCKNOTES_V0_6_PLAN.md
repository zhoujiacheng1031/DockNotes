# DockNotes v0.6 实施计划

状态：已完成

制定日期：2026-09-22

版本主题：让任务在正确的时间主动找到用户

## 1. 版本目标

v0.6 将任务中心的截止时间接入 macOS 本地通知，并建立一套可恢复、可取消、可验证的统一提醒调度机制。用户可以在通知中直接完成任务、稍后提醒或打开来源便签，也可以在每天固定时间收到今天与逾期任务摘要。

## 2. 实施范围

- 任务与便签截止时间统一生成本地通知。
- 设置页显示通知权限，支持主动请求权限及打开系统通知设置。
- 任务通知提供“标记完成”“15 分钟后提醒”“打开便签”操作。
- 每日摘要时间可使用时钟或 12/24 小时文本输入。
- 每日摘要覆盖未来七天，只在存在今天或逾期任务时发送。
- 修改日期、完成任务、编辑正文、归档、删除、撤销删除、恢复归档、切换语言、切换时区、系统唤醒和应用重启时重建提醒计划。
- 使用稳定的便签 ID 与任务 ID 关联通知，正文插入或移动任务后不会把操作应用到错误任务。

## 3. 可靠性约束

- 系统通知上限内优先保留最近到期的提醒，并为每日摘要预留容量。
- 快速连续编辑采用串行收敛调度，最终系统请求必须与最新便签状态一致。
- 完成、归档或删除后同时移除待发送和已经送达的旧通知。
- 未授权或用户关闭提醒时不保留幽灵通知；权限状态在设置页可见。
- 每日摘要使用本地日历与时区计算，跨日、切换时区和睡眠唤醒后重新校准。

## 4. 发布门槛

- 自动化验证任务提醒的生成、改期、完成取消、归档取消、恢复重建及稳定标识。
- 自动化验证每日摘要时间、今天/逾期计数、无任务静默与设置持久化。
- 自动化验证通知操作路由到正确任务，并验证稍后提醒时间。
- 完整自检、交互回归、Release 构建、签名检查和差异检查通过。
- 真实应用中完成设置页、权限状态、摘要时间输入和任务中心联动走查。
